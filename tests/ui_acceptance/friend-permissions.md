# 好友申请必填权限兼容验证记录

日期：2026-10-06。分支：`main`。产品版本保持 `1.0.0`。

## 行为与安全边界

- 仅在已绑定的好友申请窗口中查询可见提示和选项，不扫描聊天历史。
- 两项均未选择时默认选择“朋友圈”；已有“朋友圈”或“仅聊天”选择时保留。
- 使用 `SelectionItemPattern.Select()`，重新定位选项并通过 `IsSelected` 核验。
- 获取最终 Pattern 后再次核验已有选择，避免覆盖此时刚出现的人工选择；
  严格选择路径在调用前解析参数签名，不因内部 `TypeError` 重放选择。
- 此动作禁用坐标和键盘后备。局部查询不可用时禁止退回旧式全树遍历。
- 必填区域不完整、选项重复、不同分组、接口缺失或核验失败时，返回
  `FRIEND_PERMISSION_UNVERIFIED`，不可重试，停止整批并进入既有安全清理。
- 提交前重新检查权限；必填区域消失或选择丢失时不点击“确定”，不记为已提交或未知结果。
- 表单预检仍取消申请，原有真实提交授权和防重复日志不变。
- 错误文案使用固定内容，不输出申请语、备注或底层异常中的私人数据。
- 权限提示发现不按支持的选项类型预先过滤；未支持的类型也须被识别后安全拒绝。
  属性读取逐项检查共享截止时间。

## 模拟验证

`tests/test_friend_permissions.py` 使用虚构表单、真实动作执行器和工作流，覆盖：

- 普通表单、默认选择、保留已有选择、选择前新代理及人工选择变化。
- 必填提示但选项缺失、重复控件、缺少 Pattern、错误分组、双选、禁用和查询上限。
- Pattern 返回失败、异常或无状态变化时不执行鼠标后备，也不重放选择。
- 错误窗口身份、无响应、共享截止时间、提交前选择丢失或必填区域消失。
- 预检取消、停止任务、整批终止、清理执行和提交边界未触发。

相关回归：280 项通过；新增专项测试：49 项通过。Python 编译与差异检查通过。
独立审查发现的四项边界问题已通过失败用例复现并修正。
修正后全量 Python 回归：1668 项通过，1 项跳过（190.63 秒）。

## 实机兼容性待验证

当前账号不能复现截图中的必填权限分支；未操作真实微信、未提交申请。
截图不是 UIA 接口证据，模拟成功也不代表真实微信适配已经完成。

当前支持的安全路径要求：两个选项的 UIA 名称分别为“朋友圈”和“仅聊天”，
可读取 `SelectionItemPattern.IsSelected`，并能验证相同的选择分组；没有
`SelectionContainer` 时，仅使用可核验的同一直接父控件作为分组。
不满足条件则安全停止，不根据位置、样式或相似文字猜测。

后续需在能复现的机器上，针对支持的微信版本采集一次申请窗口的局部脱敏 UIA
信息，仅记录静态权限标签、类型、Pattern 可用性和选择状态，不记录申请语、
备注、标签内容或个人标识。验证选择“朋友圈”后重新读回选中状态，再取消表单；
不提交申请。完成该验收后才可标记真实兼容性通过。
